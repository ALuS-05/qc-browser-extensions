# 任务时长排序助手 - 使用说明

## 一、插件功能介绍

任务时长排序助手是一款专为 PDATA 质检平台开发的 Chrome 浏览器扩展插件，主要用于解决质检平台任务列表无法自定义排序的问题。

### 核心功能
1. **按时长排序**：在质检池和我的审核任务页面，将任务按视频时长升序或降序排列
2. **按领取时间排序**：自动记录每条任务的实际领取时间，可按最新/最早领取时间排序
3. **自动记录领取时间**：无论是手动点击认领还是使用批量领取助手批量认领，插件都会自动记录任务的准确领取时间
4. **手动批量记录**：对于历史已认领任务，可一键批量记录领取时间为当前时间

## 二、插件使用方法

### 安装方法
1. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/` 进入扩展管理页面
2. 开启右上角的"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择插件文件夹 `task-duration-sorter`
5. 插件安装成功，会出现在扩展列表中

### 使用方法

#### 1. 按时长排序
1. 打开质检平台的"质检池"或"我的审核任务"页面
2. 页面右上角会出现排序控制条
3. 点击"升序 ↑"：时长短的任务排在前面
4. 点击"降序 ↓"：时长长的任务排在前面
5. 点击"默认"：恢复平台默认排序（会刷新页面）

#### 2. 按领取时间排序
1. 打开"我的审核任务"页面
2. 点击"最新 ↓"：最新认领的任务排在前面
3. 点击"最早 ↑"：最早认领的任务排在前面

#### 3. 自动记录领取时间
- 无需手动操作，插件会自动记录
- 在质检池页面认领任务时（无论是手动点击还是批量领取），插件会自动记录该任务的准确领取时间
- 认领成功后会弹出提示："已记录任务 XXX 的领取时间"

#### 4. 手动批量记录领取时间（适用于历史任务）
1. 打开"我的审核任务"页面
2. 点击排序控制条上的蓝色按钮"记录当前页领取时间"
3. 插件会将当前页面所有没有领取时间记录的任务，统一记录为当前时间
4. 会弹出提示："已记录 X 条任务的领取时间为当前时间"
5. 然后就可以按领取时间排序了

**注意**：手动记录的领取时间是点击按钮时的当前时间，不是实际领取时间。从现在开始新认领的任务，插件会自动记录准确的领取时间。

#### 5. 隐藏/显示排序控制条
- 点击控制条右上角的"×"按钮可临时隐藏控制条
- 隐藏后 3 秒会自动重新显示

## 三、版本更新日志

### v1.2.2（2026-09-18）
**修复问题**
- 修复插件弹窗状态错误显示"当前页面不适用"的问题（域名判断误写成了其他平台域名）
- 修复页面加载慢、平台卡顿或网络不稳定时，排序浮动条不显示且之后再也不出现的问题
- 修复在质检池和"我的审核任务"之间切换（单页应用路由切换）时，插件有时失效的问题
- 优化注入机制：改为持续监听 + 轮询兜底，页面加载完成后自动出现排序条，无需手动刷新
- 非目标页面（如统计首页）自动隐藏排序条，回到任务页面自动显示

### v1.2.1（2026-09-17）
**新增功能**
- 增加定时扫描功能：每2秒自动扫描质检池页面，检测任务状态变化
- 兼容批量领取助手：无论是手动点击认领还是使用批量领取助手批量认领，都能自动记录领取时间
- 增加"记录当前页领取时间"按钮：可一键批量记录历史已认领任务的领取时间为当前时间
- 增加操作提示 Toast：认领成功、记录成功时会弹出短暂提示

**修复问题**
- 修复使用批量领取助手认领任务时，领取时间无法被记录的问题
- 修复按领取时间排序时，实际按提交时间排序的问题

### v1.2.0（2026-09-17）

- 增加按实际领取时间排序功能：最新领取/最早领取
- 自动记录任务领取时间：点击认领按钮时自动记录准确时间
- 领取时间本地存储：关闭浏览器不丢失
