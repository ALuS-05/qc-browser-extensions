# 视频质检助手 — 浏览器插件 v2.0

面向视频质检员的工作辅助插件，在原版「视频时长记录器」基础上增强，专为质检流程设计。

## 新增功能（相比原版）

| 功能 | 说明 |
|---|---|
| 质检计时 | 打开视频页面自动开始计时，支持暂停/继续，提交结果时记录耗时 |
| 通过/不通过 | 弹窗中一键标记质检结果 |
| 不通过原因 | 可自定义原因标签，支持多选 + 备注 |
| 每日统计 | 今日质检数、通过/不通过数、通过率、总耗时、平均耗时 |
| CSV 导出 | 导出含任务ID、时长、耗时、结果、原因的明细表，可用 Excel 打开 |
| TXT 导出 | 导出文本格式质检报告 |
| 任务去重 | 同一任务重新打开不重复创建，而是重置计时继续质检 |
| 设置页面 | 可自定义不通过原因标签 |

## 安装方法

1. 打开 `chrome://extensions/`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本文件夹 `video-qc-tracker`
5. 安装完成

## 使用流程

1. **领取任务**：在质检平台领取视频质检任务
2. **开始质检**：点击进入任务视频页面，插件自动检测到视频并开始计时
3. **查看进度**：点击工具栏插件图标，可看到当前质检耗时
4. **暂停计时**：如需中途暂停，点击「暂停计时」，回来后点「继续计时」
5. **提交结果**：
   - 视频合格 → 点「通过」
   - 视频不合格 → 点「不通过」→ 选择原因（可多选）→ 可补充备注 → 「确认不通过」
6. **查看统计**：弹窗中显示今日质检数据
7. **导出报表**：点击「导出 CSV」或「导出 TXT」

## 数据字段说明

每条记录包含：
- 任务ID（从URL自动提取）
- 视频标题、页面URL
- 视频时长
- 质检耗时
- 质检结果（通过/不通过/未完成）
- 不通过原因
- 开始时间、提交时间

## 注意事项

- 原版「视频时长记录器」插件可同时安装，两者数据独立互不影响
- 任务ID从URL参数中自动提取（支持 taskId、id、videoId 等常见参数名）
- 如平台URL结构特殊导致任务ID无法识别，同一页面的不同视频按时长区分
- 直播流（duration 为 Infinity）不会被记录
