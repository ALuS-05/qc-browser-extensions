# 视频质检助手 - 使用说明

## 一、插件功能介绍

视频质检助手是一款专为视频质检工作开发的 Chrome 浏览器扩展插件，集成了视频质检工作中需要的多种辅助功能，帮助质检员更高效地完成质检工作。

### 核心功能
1. **自动记录视频时长**：进入视频播放页面后，自动识别并记录视频时长
2. **质检计时**：记录每条视频的质检耗时，帮助统计工作效率
3. **通过/不通过标记**：手动标记每条视频的质检结果（通过/不通过）
4. **不通过原因记录**：对于不通过的视频，可记录具体的不通过原因
5. **每日统计**：按日期统计质检数量、通过数量、不通过数量、总质检时长等
6. **CSV 导出**：支持将质检记录导出为 CSV 文件，方便数据分析和报表制作
7. **设置页面**：可自定义插件的各项参数

## 二、插件使用方法

### 安装方法
1. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/` 进入扩展管理页面
2. 开启右上角的"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择插件文件夹 `video-qc-tracker`
5. 插件安装成功，会出现在扩展列表中

### 使用方法

#### 1. 自动记录视频时长
1. 打开包含视频的质检页面
2. 播放视频，插件自动识别视频时长并记录
3. 点击浏览器工具栏的插件图标，可查看记录的数据

#### 2. 质检计时
1. 进入视频质检页面后，插件自动开始计时
2. 完成质检后，点击"通过"或"不通过"，计时自动停止
3. 每条记录会显示质检耗时

#### 3. 标记通过/不通过
1. 完成视频质检后，在插件面板中点击对应的记录
2. 选择"通过"或"不通过"
3. 如果选择"不通过"，会弹出输入框让你填写不通过原因
4. 记录会自动保存并更新统计数据

#### 4. 记录不通过原因
1. 对于不通过的视频，在标记为不通过时会弹出原因输入框
2. 输入具体的不通过原因（如：画面模糊、声音不同步、内容违规等）
3. 原因会保存在该条记录中，方便后续复查和统计

#### 5. 查看每日统计
1. 点击浏览器工具栏的插件图标，打开插件面板
2. 面板顶部显示统计区域：
   - 今日质检数量
   - 通过数量/不通过数量
   - 总质检时长
   - 平均质检耗时
3. 可按日期筛选查看历史统计

#### 6. 导出 CSV
1. 打开插件面板
2. 点击"导出 CSV"按钮
3. 选择导出的日期范围（或全部数据）
4. CSV 文件自动下载到浏览器默认下载目录
5. 可用 Excel 打开 CSV 文件进行数据分析和报表制作

#### 7. 插件设置
1. 在扩展管理页面，点击插件的"详情"
2. 点击"扩展程序选项"进入设置页面
3. 可自定义的设置包括：
   - 是否自动开始计时
   - 是否自动记录视频时长
   - 不通过原因的预设选项
   - 导出文件的格式和字段
   - 数据保留时长等

## 三、常见问题

### Q1：插件支持哪些网站？
A：插件支持所有包含 HTML5 视频播放器的网站，在设置中可以配置需要生效的网站域名。

### Q2：数据存储在哪里？会上传到服务器吗？
A：所有数据都存储在浏览器本地（chrome.storage.local），不会上传到任何服务器，数据安全有保障。

### Q3：换电脑了数据怎么办？
A：可以在旧电脑上导出 CSV 或 JSON 备份文件，然后在新电脑上导入。

### Q4：可以和视频时长记录器同时使用吗？
A：可以。两个插件功能互补，视频时长记录器侧重时长记录和悬浮球操作，视频质检助手侧重质检流程管理和统计分析，可以同时安装使用。
