# 任务批量领取助手 - 使用说明

## 一、插件功能介绍

任务批量领取助手是一款专为 PDATA 质检平台开发的 Chrome 浏览器扩展插件，主要解决质检平台点击"认领"任务后自动跳转到已认领任务页面，导致无法一次性批量领取多条任务的问题。

### 核心功能
1. **认领不跳转**：点击认领按钮后，不再自动跳转到已认领任务页面，停留在当前质检池页面
2. **后台批量认领**：通过后台 API 直接认领任务，不影响页面操作
3. **认领成功验证**：每条任务认领后验证是否真正认领成功，避免页面显示已认领但实际未成功的情况
4. **冲突检测**：检测任务是否已被他人领取，避免因页面未刷新导致的误判
5. **认领结果提示**：认领成功/失败都有明确提示，方便统计实际认领数量

## 二、插件使用方法

### 安装方法
1. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/` 进入扩展管理页面
2. 开启右上角的"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择插件文件夹 `task-claim-helper`
5. 插件安装成功，会出现在扩展列表中

### 使用方法

#### 1. 批量认领任务
1. 打开质检平台的"质检池"（待认领任务）页面
2. 找到想要认领的任务，点击任务右侧的"认领"按钮
3. 插件会在后台通过 API 认领该任务
4. 认领成功后，按钮会变成"已认领"状态，页面顶部弹出"认领成功"提示
5. **页面不会跳转**，你可以继续点击其他任务的"认领"按钮，一次性认领多条任务
6. 全部认领完成后，手动切换到"我的审核任务"页面查看已认领的任务

#### 2. 认领结果验证
- 每条任务认领后，插件会验证是否真正认领成功
- 如果认领成功：按钮变灰显示"已认领"，弹出成功提示
- 如果认领失败（如任务已被他人领取）：弹出失败提示，按钮保持可点击状态
- 实际认领数量以"我的审核任务"页面为准

#### 3. 注意事项
- 认领任务时建议不要一次性点击过快，每条间隔 0.5-1 秒，避免服务器限流
- 如果出现点击后按钮变灰但实际未认领成功的情况，刷新页面后重新认领
- 插件只在质检平台的质检池页面生效，其他页面不影响

## 三、常见问题

### Q1：为什么点击认领后按钮变灰了，但我的审核任务里没有这条任务？
A：可能是任务在你点击的同时被其他人认领走了，页面还没刷新所以按钮显示已认领。插件会验证认领结果，如果实际未成功会提示。刷新页面后重新认领即可。

### Q2：一次性最多可以认领多少条任务？
A：没有明确上限，但建议每次认领 5-10 条，间隔操作，避免服务器压力过大导致认领失败。

### Q3：这个插件会影响其他人认领任务吗？
A：不会。插件只是在你本地浏览器拦截了页面跳转，通过正常的 API 接口认领任务，和手动点击认领的效果完全一样，不会对其他人造成影响。

### Q4：我和别人同时点击同一个任务会冲突吗？
A：会有竞争，以服务器实际处理结果为准。先到达服务器的请求会认领成功，后到达的会失败。插件会验证结果并提示。

## 四、版本更新日志

### v1.2.0（2026-10-10）
**修复AC平台适配问题**
- 修复认领按钮点击后仍会跳转的问题：AC平台整个应用内容在iframe（id=persistentHostActive）中运行，旧版本content_scripts的all_frames设为false，导致content script只注入主页面、不注入iframe，无法拦截iframe内认领按钮的点击事件。现已将all_frames改为true，content script会同时注入主页面和所有iframe，能正确拦截认领按钮点击并阻止跳转

- 优化认领结果提示：成功/失败都有明确提示

**修复问题**

- 修复因页面未刷新导致的误判问题
