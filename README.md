# 质检平台浏览器插件工具集

这是一套为视频质检工作开发的浏览器插件集合，用于提升质检工作效率。

## 插件列表

### 1. 视频时长记录器 (video-duration-tracker)
- **当前版本**: v1.0.14
- **功能**: 自动识别并记录浏览器页面中播放视频的时长，支持自动识别质检结果（通过/不通过），悬浮球操作界面
- **适配平台**: PDATA平台、AC平台（AetherCapture）

### 2. 任务批量领取助手 (task-claim-helper)
- **当前版本**: v1.2.0
- **功能**: 在待认领任务页面点击认领后不跳转页面，支持连续批量认领多条任务
- **适配平台**: PDATA平台、AC平台（AetherCapture）

### 3. 任务时长排序助手 (task-duration-sorter)
- **功能**: 将待认领任务池里的任务按时长进行升/降序排列，也支持按领取时间排序
- **适配平台**: PDATA平台、AC平台（AetherCapture）

### 4. 视频质检助手 (video-qc-tracker)
- **功能**: 质检工作辅助工具

### 5. 网络请求监控助手 (network-monitor)
- **功能**: 可视化显示浏览器发送的请求和质检平台之间的连接进度，显示每条请求的状态和耗时

### 6. 模拟质检平台 (mock-pdata-platform)
- **功能**: 本地模拟的质检平台，用于测试插件功能，无需连接真实平台
- **使用方法**: 双击运行"启动模拟平台.bat"，然后在浏览器打开提示的地址

## 安装方法

1. 打开 Chrome 或 Edge 浏览器，地址栏输入 `chrome://extensions/`
2. 开启右上角的"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择对应插件的文件夹
5. 插件安装成功
