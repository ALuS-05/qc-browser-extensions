# 网络请求监控助手 使用说明

## 功能介绍
实时监控网页发出的所有网络请求，可视化显示每个请求的加载进度和各阶段耗时，帮助定位网页卡顿的原因。

## 使用方法
1. 打开 Chrome 浏览器 → 地址栏输入 `chrome://extensions/`
2. 开启右上角"开发者模式"
3. 点击"加载已解压的扩展程序"，选择本插件文件夹
4. 打开任意网页，右下角会出现一个蓝色地球图标 🌐
5. 点击图标展开监控面板，查看所有请求详情

## 界面说明
- **悬浮球**：右下角蓝色圆形图标，右上角红色数字表示当前进行中的请求数
- **统计栏**：总请求数、进行中、完成、失败
- **请求列表**：
  - 绿色 GET / 蓝色 POST —— 请求方法
  - URL —— 请求地址（截断显示）
  - 状态码 —— 200成功 / 红色失败 / 黄色等待中
  - 耗时 —— 总耗时
- **点击任意请求**展开详细时间分解：
  - **DNS**（灰色）—— 域名解析时间
  - **TCP**（蓝色）—— 建立连接时间
  - **TLS**（紫色）—— 加密握手时间
  - **等待**（橙色）—— 服务器处理请求时间（最常见的瓶颈）
  - **下载**（绿色）—— 内容传输时间

## 怎么用它诊断卡顿
- **橙色"等待"占比最大** → 平台后端响应慢，是服务器问题
- **蓝色TCP/紫色TLS占比大** → 网络链路问题，可能是公司网络或VPN
- **绿色"下载"占比大** → 带宽不够，数据传得慢
- **灰色DNS占比大** → 域名解析慢，可以换DNS
