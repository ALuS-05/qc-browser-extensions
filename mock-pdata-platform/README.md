# PDATA质检平台 - 模拟演示环境（简易版）

## 用途
用于面试演示 Chrome 插件（视频时长记录器、任务批量领取助手、任务时长排序助手）的模拟质检平台。

## 快速启动
双击 `启动模拟平台.bat`，会自动：
1. 启动本地 HTTP 服务器（端口 8080）
2. 自动打开浏览器访问 http://localhost:8080

如果浏览器没有自动打开，手动访问 http://localhost:8080

## 页面说明
- **统计首页**：数据概览（简易版占位）
- **录制记录**：运营管理页面（简易版占位）
- **质检池**：待认领任务列表，可点击"认领"按钮（不跳转页面）
- **我的审核任务**：已认领任务列表，可点击"审核"进入详情页
- **审核详情**：任务信息 + 视频播放器 + 检查项 + 通过/不通过 + 提交审核

## 插件演示说明
1. **视频时长记录器**：进入审核详情页，播放视频，插件会自动识别并记录视频时长；点击"通过/不通过"后提交审核，插件会自动记录审核结果
2. **任务批量领取助手**：在质检池页面，可批量认领任务不跳转
3. **任务时长排序助手**：在质检池页面，点击右上角"时长排序"可按时长升序/降序排列

## 数据存储
任务认领状态、审核结果等数据存在浏览器 localStorage 中，刷新页面不丢失。
如需重置数据，在浏览器控制台执行：`localStorage.removeItem('mock_pdata_state')` 然后刷新页面。

## 注意事项
- 必须通过 `http://localhost:8080` 访问，不要直接双击 index.html（否则 Chrome 插件可能无法在 file:// 协议下运行）
- 视频使用的是公开的示例视频（约10秒），仅用于演示插件识别功能
