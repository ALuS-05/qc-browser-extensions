# 视频时长记录器 - 使用说明

## 一、插件功能介绍

视频时长记录器是一款专为视频质检工作开发的 Chrome 浏览器扩展插件，能够自动识别并记录网页中播放视频的时长，大幅提升质检工作效率。

### 核心功能
1. **自动识别视频时长**：进入视频播放页面后，插件自动识别视频时长并记录
2. **审核结果自动识别**：自动识别视频质检的通过/不通过结果，用绿色勾/红色叉标记
3. **数据统计**：统计通过/不通过/未审核视频数量，以及通过视频总时长
4. **悬浮球操作**：页面右侧悬浮球，点击展开插件面板，可拖动位置，右键关闭；点击插件图标自动显示悬浮球
5. **数据编辑删除**：每条记录支持编辑（视频时长、名称、日期等）和删除
6. **导入导出**：支持导出 TXT/JSON 文件，支持导入 JSON 数据（JSON导入导出在"更多"菜单中）
7. **智能去重**：30分钟窗口内同一视频只更新记录时间不重复记录；永久去重，同一视频不再重复记录
8. **面板大小可调**：插件面板支持拖拽边框调整大小

## 二、插件使用方法

### 安装方法
1. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/` 进入扩展管理页面
2. 开启右上角的"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择插件文件夹 `video-duration-tracker`
5. 插件安装成功，会出现在扩展列表中

### 使用方法

#### 1. 自动记录视频时长
1. 打开包含视频的网页（如质检平台的审核详情页）
2. 播放视频，插件会自动识别视频时长并记录
3. 页面右侧会出现悬浮球，点击可查看记录的数据

#### 2. 审核结果自动识别
1. 在质检页面点击"通过"或"不通过"并提交审核
2. 插件自动识别审核结果
3. 对应视频记录前会显示标记：
   - 绿色小勾 ✓ = 审核通过
   - 红色小叉 ✗ = 审核不通过
   - 灰色圆圈 ○ = 未审核

#### 3. 查看统计数据
1. 点击悬浮球打开插件面板
2. 面板顶部显示统计区域：
   - 通过视频数量及总时长
   - 不通过视频数量
   - 未审核视频数量

#### 4. 编辑记录
1. 点击悬浮球打开插件面板
2. 找到要编辑的记录，点击该条记录后的"编辑"按钮
3. 在弹出的编辑框中修改视频时长、名称、日期等信息
4. 点击保存完成编辑

#### 5. 删除记录
1. 点击悬浮球打开插件面板
2. 找到要删除的记录，点击该条记录后的"删除"按钮
3. 确认删除后，该条记录被移除

#### 6. 导出数据
1. 点击悬浮球打开插件面板
2. 点击"导出 TXT"按钮：导出为纯文本格式
3. 点击"⚙️ 更多"按钮展开更多选项
4. 点击"导出数据(JSON)"按钮：导出为 JSON 格式（可用于备份和导入）
5. 文件会自动下载到浏览器默认下载目录

#### 7. 导入数据
1. 点击悬浮球打开插件面板
2. 点击"⚙️ 更多"按钮展开更多选项
3. 点击"导入数据(JSON)"按钮
4. 选择之前导出的 JSON 文件
5. 数据导入完成，记录会合并到现有数据中

#### 8. 悬浮球操作
- **默认显示**：插件默认在页面右侧显示悬浮球
- **点击悬浮球**：展开/收起插件面板
- **拖动悬浮球**：按住鼠标左键拖动，可移动悬浮球位置
- **右键悬浮球**：弹出菜单，选择关闭悬浮球
- **重新显示悬浮球**：点击浏览器工具栏的插件图标，悬浮球会自动显示
- **调整面板大小**：鼠标移到面板边框，按住拖动可调整面板大小

## 三、版本更新日志

### v1.0.14（2026-10-10）
**修复评判结果无法识别的根本原因**
- 修复任务ID提取失败：AC平台任务ID格式为`日期_时间_UUID`（如`20261008_121530_963f384f-a8b6-...`），旧正则`/\b(\d{8}_\d{4,})\b/`结尾的`\b`单词边界在时间部分后面跟着下划线（也是单词字符）时不成立，导致匹配失败。任务ID提取失败后，视频记录的taskFromPage为空，审核提交时的sessionId也为空，评判结果无法关联到对应的视频记录。现已去掉结尾的`\b`，能正确提取任务ID

### v1.0.13（2026-10-10）
**基于 AC 平台真实 DOM 结构的深度修复**
- 修复质检结果无法识别：通过实际进入AC平台审核页面查看DOM结构，发现结论下拉框id="conclusion"、className为空、父元素是label标签。旧代码按class匹配和容器选择器（不含label）导致找不到下拉框。现已增加按id="conclusion"精确匹配、容器选择器增加label、并检查options中的枚举值（不只是当前value）
- 修复视频时长无法稳定识别：AC平台整个应用内容在iframe（id=persistentHostActive）中，视频元素id="reviewVideo"采用动态加载（排队完成后才设置src），导致duration长时间为null。现已增加从页面提取"采集时长"字段作为备选（页面直接显示了视频时长秒数），视频duration未准备好时先用采集时长记录，后续durationchange时自动更新
- 修复URL不一致问题：iframe的URL带__aether_frame=1参数，与主页面URL不同导致去重和审核匹配失败。现已在URL规范化时去掉该参数

### v1.0.12（2026-10-10）
**修复 AC 平台适配问题（第二版）**
- 修复质检结果无法识别：AC平台的结论下拉框实际是原生`<select>`，但其value值不是英文PASS/REJECT而是中文或数字，旧代码按英文枚举匹配导致找不到下拉框。现已去掉英文value强制验证，增加按选项文本（通过/不通过/废弃/返工/待复核）匹配的兜底逻辑
- 修复视频时长无法稳定识别：新增每2秒定时强制扫描机制，检测到正在播放的视频立即记录；若duration未准备好则自动绑定durationchange/loadedmetadata事件等待，确保AC平台自定义播放器的视频一定能被记录

### v1.0.11（2026-10-10）
**适配 AC 平台更新（AetherCapture 管理平台）**
- 修复 AC 平台更新后质检结果（通过/不通过）无法自动识别的问题：AC平台将原生 select 下拉框换成了自定义 div 下拉组件，新增对自定义下拉组件的三层识别逻辑（结论标签附近查找、role=combobox 全局扫描、页面文本正则匹配）
- 修复视频标题显示为"AetherCapture 管理平台"的问题：新增从页面提取"任务目标"文本作为视频标题，更有辨识度
- 增强 AC 平台视频识别稳定性：增加更多扫描时间点（500ms~30秒共10次），URL切换后增加7次重试，页面从后台切回前台时立即重新扫描，空闲看门狗超时从30秒延长到45秒

### v1.0.10（2026-09-18）
**修复BUG**
- 修复旧PDATA平台偶发无法识别视频时长的问题：原代码在发送消息前就将视频标记为"已记录"，若消息发送失败（如后台Service Worker休眠），视频会被标记但实际未记录，且后续事件不再重试。现将标记逻辑移至消息发送成功的回调中，发送失败则保留重试机会
